# DeviceBlocker

A fun Android app prototype exploring VPN-based firewalls and IP blocking. Built with Kotlin and Jetpack Compose.

## Features

- Start and stop the VPN firewall service
- Add and remove IP addresses from the block list
- View example devices on a Wi-Fi network

## Project status

This is an experimental project for learning and fun, not a production-ready security tool. The device list uses hard-coded demo data, and real network scanning and full VPN traffic filtering are not implemented. The current version also has a known Android resource-linking error involving `Theme.Black.NoActionBar`.
